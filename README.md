6. Jednoduchý program v Pythonu

Pomocí Pythonu můžeme například zjistit, zda je automobil rychlejší než 200 km/h.

python
auto = "BMW M4 Competition"
maximalni_rychlost = 250

print("Automobil:", auto)
print("Maximální rychlost:", maximalni_rychlost, "km/h")

if maximalni_rychlost > 200:
    print("Toto auto je velmi rychlé! 🏎️")
else:
    print("Toto auto je pomalejší.")
